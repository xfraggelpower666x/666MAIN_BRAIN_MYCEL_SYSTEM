## Learning cycle

OBSERVATION
→ EVIDENCE_BINDING
→ HYPOTHESIS
→ ROUTING_OR_CATALOG_OUTCOME
→ FEEDBACK
→ CAUSAL_UPDATE_CANDIDATE
→ CONTRADICTION_CHECK
→ STALE_STATE_CHECK
→ PROMOTE_OR_REJECT
→ CURRENT_STATE_DELTA

## What PSYLLO may learn

- which catalog relations are repeatedly useful
- which routing paths fail or succeed
- which evidence sources become stale
- which card properties require revalidation
- which UI routes are confusing or effective
- which recurring chaos clusters can be resolved into stable directed workflows

## What PSYLLO may not learn into authority

- invented branch tokens
- inferred secrets
- foreign system IDs without verification
- foreign native authority changes
- unverified runtime claims
