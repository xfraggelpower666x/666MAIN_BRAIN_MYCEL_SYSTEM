# SYSTEM CARD SCHEMA

Every cataloged native system receives a card. Cards are navigation/evidence objects, not copies of the foreign system.

## Required fields

- CARD_ID
- SYSTEM_FAMILY
- DISPLAY_NAME
- SYSTEM_ID — only if verified
- NATIVE_ROLE
- CURRENT_POINTER_LOCATOR — reference or DISCOVER_ON_DEMAND
- AUTHORITY_OWNER
- VALID_DIRECT_TRIGGERS
- CAPABILITIES
- RELATIONS
- INBOUND_HANDOFF_RULE
- OUTBOUND_HANDOFF_RULE
- AUTOACTIVATION_ALLOWED
- CROSS_SYSTEM_MERGE_ALLOWED
- LAST_VERIFIED_EVIDENCE
- STATUS

## Card states

VERIFIED
PARTIAL
OFFEN
BLOCKIERT
STALE_REVALIDATION_REQUIRED
CONFLICT_QUARANTINE

## Rule

CARD_NE_NATIVE_AUTHORITY=TRUE
CARD_NE_CURRENT_POINTER=TRUE
CARD_MUST_REVALIDATE_BEFORE_EXECUTION=TRUE
