Extends the twelve existing Operations Center views and current Coding Workbench without replacement.
Modes: OVERVIEW | DEVELOPMENT | FACETS | GUIDANCE | EVIDENCE | CONTINUITY. Every mode is a projection of the same verified source HEAD, owner, scope, current evidence and return anchor.

Every action needs label, source, owner, target scope, preconditions, effect and actual host action or reason unavailable. A control must perform its stated local action, submit an exact registered command on a real user click, or render as explanatory text. Merely opening a foreign card never activates it. A UI handoff stores view preferences only, never native work authority. Rehydrate native work first and use preferences only if revision/lineage match. Text fallback is mandatory when interactive rendering is unavailable. No invented status, charts, background service, test results or persisted changes.

Related: UI/OPERATIONS_CENTER.md; UI/VISUAL_INTELLIGENCE.md; DAEMON/GUIDANCE_CONTRACT.md; INTEGRATIONS/PSYLLO_CODING/README.md.
