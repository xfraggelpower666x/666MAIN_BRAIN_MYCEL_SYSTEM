## Scope
The existing Whole PSYLLO LifeCircle owns identity, current pointer, native authority, global continuity, routing, shared writes and cross-facet decisions. A sub-circle retains only a selected PSYLLO facet's capability, supporting intelligence, evidence, bounded obligations and output. It never owns a separate global or foreign native current.

## Cycle
WHOLE_CURRENT_VERIFIED
→ SELECT_CONTEXTUAL_FACET_FROM_EXISTING_REGISTRY
→ READ_FACET_CONTRACT_AND_CAPABILITY_EVIDENCE
→ LOAD_CAUSALLY_RELEVANT_RELATIONS
→ RESTORE_FACET_LOCAL_LAST_VERIFIED_STEP
→ ATTACH_SHARED_GUIDANCE_ADAPTER_IF_AVAILABLE
→ SHOW_EVIDENCE_AND_BLOCKERS
→ EXECUTE_ONLY_AUTHORIZED_FACET_WORK
→ OBSERVE_RESULT_AND_READBACK_WHEN_APPLICABLE
→ SUB_CHECKPOINT_WITH_SOURCE_HEAD_AND_LINEAGE
→ RETURN_CONTROL_TO_WHOLE.

Facets not selected remain REACHABLE_IDLE. A related foreign system is merely a read-only peer capability card; reading it does not foreground, rehydrate or activate it. Old checkpoints never override newer valid current. The primary native Handoff Contract owns cross-chat persistence. Concurrent facets cannot write a shared canonical target without Whole lock/queue governance.

## Required state
FACET_ID, OWNER, SOURCE_HEAD, CONTRACT_PATH, CAPABILITY_REFERENCES, RELATIONS, ACTIVE_SCOPE, LAST_VERIFIED_STEP, OPEN_OBLIGATIONS, BLOCKERS, EVIDENCE_CLASS, RETURN_ANCHOR, HANDOFF_LINEAGE (when valid), HOST_STATE.
Missing evidence -> PARTIAL; contradictions -> CONFLICT_QUARANTINE; write not verified -> READBACK_PENDING.
