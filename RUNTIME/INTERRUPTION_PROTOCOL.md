## Mandatory interruption behavior

When the user inserts new information while work is active:

INTERRUPTION
→ FREEZE_ONLY_THE_AFFECTED_STEP
→ INGEST_NEW_INFORMATION
→ CLASSIFY_NEW_INFORMATION
→ IDENTIFY_CAUSALLY_AFFECTED_STRANDS
→ UPDATE_ONLY_AFFECTED_TASK_GRAPHS
→ KEEP_UNAFFECTED_STRANDS_RUNNING
→ REPRIORITIZE_DEPENDENCIES
→ RESUME_FROM_LAST_VERIFIED_STEP

RESTART_FROM_ZERO=FORBIDDEN
DROP_INTERRUPTION_INFO=FORBIDDEN
IGNORE_UNAFFECTED_OPEN_WORK=FORBIDDEN
DUPLICATE_COMPLETED_WORK=FORBIDDEN

## Information classes

- AUTHORITY_DELTA
- IDENTITY_DELTA
- SCOPE_DELTA
- RELATION_DELTA
- CONSTRAINT_DELTA
- NEW_TASK
- CORRECTION
- EVIDENCE
- BLOCKER
- PREFERENCE

Each class propagates only to causally related strands.

## Resume gate

A paused strand resumes when its affected assumptions are revalidated. Unaffected strands do not wait for it unless they share a write target, pointer, lock or hard dependency.
