# Intelligent Menüs

Der direkte Einstieg lautet `L.Y.V.R.A. CODING PROFI — INTELLIGENT MENÜS`. Die bestehende [Projektansicht](../../references/chat-navigation.md) bleibt der Einstieg für Development, ToolStarter und LiveCircle. Die [Intelligent UI](../sceeri-visual-intelligent-ui/SKILL.md) fügt die Modi **Projektansichten**, **Visualformen** und **Charts** hinzu.

Nutze den [gemeinsamen Daemon-Vertrag](../sceeri-visual-intelligent-ui/references/visual-companion.md). Ordne Vorschläge nach bestätigtem Readback, Blocker, fehlender Angabe und fachlicher Gegenprobe. Zeige im aktiven Schritt eine priorisierte Aktion mit Bezug zur Quelle. Biete weitere Wege an, wenn sie parallel möglich sind oder einen sichtbaren Rückweg liefern. Bei mehrdeutiger Absicht halte die Auswahl offen. Ansichtswechsel erhalten Eingaben und Projektfokus. Verwende tatsächliche Host-Bedienelemente für deren beobachtete Funktionen. Ein kopierter Auftrag wird über den Composer gesendet. Eine Rückkehr über LiveCircle nutzt den bestätigten Projekt-Checkpoint.

Bei strukturiertem Projektstand verwende die [beleggebundenen Aktionsvorschläge](../sceeri-visual-intelligent-ui/references/ui-contract.md#beleggebundene-aktionsvorschläge). Das Menü zeigt eine abhängige Aktion erst nach verifiziertem Vorgänger. Eine gemerkte Priorität wirkt innerhalb derselben Projektbasis und bei fachlichem Gleichrang.
