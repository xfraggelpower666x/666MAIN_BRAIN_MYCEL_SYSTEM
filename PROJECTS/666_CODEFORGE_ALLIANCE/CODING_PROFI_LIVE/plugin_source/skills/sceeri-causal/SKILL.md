# sceeri-causal

1. Establish timeline and expected vs observed behavior; identify controlled variables and possible confounders.
2. Create causal hypotheses, each with mechanism, supportive/contradictory evidence, falsifying test and blast radius.
3. Distinguish direct observation, inference, correlation, counterfactual prediction, causal confirmation.
4. Rank next diagnostic actions by information gain, safety, reversibility and cost; never claim certainty from one coincident event.
5. Re-check dependencies and regression risks before proposing any patch.

## Kausaltyp und systemweite Wirkung

Benenne für einen relevanten Zusammenhang Auslöser, Mechanismus, Zustandsänderung und Effekt. Unterscheide notwendige, hinreichende und beitragende Bedingungen von bloßer Korrelation. Grenze die Aussage auf die belegten Umstände ein und nenne eine Gegenbeobachtung, die sie schwächen würde. Bei Wechselwirkungen weise lokales Komponentenverhalten und Systemwirkung getrennt aus. Reine Nähe im Log begründet keine Kausalität.
