Das ZIP enthält Manifest, Fachfacetten und den ToolStarter-Kern mit Profilen und Werkzeugkarten. Für echte Tests, GitHub- oder Drive-Zugriffe gilt die tatsächlich bereitgestellte Host-Fähigkeit. Alternativ dienen Dateien, Diffs und Logs als Eingabe. Entworfener Zielcode kann als Antwort geliefert werden und läuft mit seinem eigenen Projekteinstieg. Die [Herkunft](references/herkunft.md) dokumentiert die ausgewerteten Quellen.

Starte mit `L.Y.V.R.A. CODING PROFI — INTELLIGENT UI · VISUALFORMEN`.
Die Oberfläche verbindet zehn Visualformen, interaktive Charts,
Projektansichten und den Visual Daemon. Das Menü leitet Folgeaktionen
aus belegten Voraussetzungen ab und zeigt Quelle, Wirkung und Gegenprobe.

[Einbauanleitung](skills/sceeri-visual-intelligent-ui/template/README.md).
