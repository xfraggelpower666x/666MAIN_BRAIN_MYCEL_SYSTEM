# Peer-Quellen für die Coding-Integration v0.63.0

Quellabgleich am 14.11.2026. MAIN BRAIN Plugin v0.2.4 · `pluginrel_6af8bab49ad88191bf8ce508985a6d56`. CODING PROFI Basis v0.62.0 · `pluginrel_6af8b6ae0e0c8191a1d8b326f515d5d7`. 150 gemeinsame Textdateien waren beim Direktvergleich identisch. Aus den Abweichungen wurden Projektmethoden in vorhandene Skills eingebunden. Die neun nativen MAIN-BRAIN-Skills bleiben ihrer Identität und Repo-Authority zugeordnet. MAIN BRAINs GitHub-Pointer dokumentiert eine laufende Migration. Repository-Quelle, Plugin-Release und Host-Nachweis haben eigene Zeitpunkte.

Die visuelle Vorlage ist im vorhandenen Coding-Navigationsvertrag und im MAIN-BRAIN-Visualprofil als Family Post v0.9.26 dokumentiert. Der geteilte Chat lieferte bei der Prüfung keine lesbare Konversation. Die technische LYVRA-Quelle ergänzt Capability-Provenienz und binären Direktweg vor Fallback. |
