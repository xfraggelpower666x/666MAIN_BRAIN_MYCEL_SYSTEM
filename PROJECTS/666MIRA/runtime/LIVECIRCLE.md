# MIRA LiveCircle

Current verifizieren → direkten Nutzereinstieg zuordnen → Quelle und Sprache klären → MIRA NORMAL anwenden → optionales Preset ergänzen → FORCE-Gegenprüfung → Ausgabe → Evidenz und offenes Ergebnis an den MIRA-Handoff binden.

Unterbrechungen erhalten den belegten Rückkehranker. Visuelle Begleitung zeigt Stand, Ursache, gültige nächste Aktion und Gegenprobe. Anzeigen, UI-Handoffs und Nutzerpräferenzen erteilen keine Schreibfreigabe.

Native Updates: Rehydrate → Audit → autorisierte Änderung und Prechange-Recovery → Re-Audit → Freeze → Pointer zuletzt → Readback. Bei geänderter Basis neu prüfen. Ohne Scope, Lock-Entscheidung oder direkten Readback bleibt die Veröffentlichung offen.
