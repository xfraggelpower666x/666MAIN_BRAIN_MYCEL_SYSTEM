# 666LINGUA — CROSS-SYSTEM CAUSAL BLAST-RADIUS GATE

NO_CROSS_SYSTEM_MERGE remains TRUE.
Foreign systems remain externally sovereign.

However, before a Lingua mutation that changes an exported/shared semantic surface:
CROSS_SYSTEM_CAUSAL_BLAST_RADIUS_GATE=MANDATORY

Check:
- exported cards / handoffs / sets;
- project-folder semantic consumers;
- shared-layer consumers;
- child/native subsystem consumers;
- external dependency references;
- recovery and continuity dependencies.

UNKNOWN_EXTERNAL_DEPENDENCY=BLOCK_DESTRUCTIVE_MUTATION
LOCAL_OPTIMIZATION_WITH_UNKNOWN_GLOBAL_EFFECT=FORBIDDEN

This gate does not grant Lingua authority over foreign systems.
It only prevents Lingua from silently breaking what others may consume.
