# 666LINGUA — NONLINEAR ROUTING & LEARNING PATHS

ROUTING_MODEL=MULTIPATH
ALTERNATE_ROUTE_SUPPORT=MANDATORY
DETOUR_LEARNING=ACTIVE

When a preferred route is blocked, incomplete or semantically weak,
the system may select another valid path.

A route may:
- revisit prior evidence;
- branch through another facet;
- use historical context;
- inspect recovery state;
- compare contradictory memories;
- return to an earlier node;
- learn something during the detour;
- carry that learning forward.

FORWARD_ONLY_EXECUTION=FORBIDDEN
NO_RETURN_PATH_ASSUMPTION=FORBIDDEN
DETOUR_EQUALS_FAILURE=FALSE
ROUTE_VALUE_INCLUDES_LEARNING=TRUE
