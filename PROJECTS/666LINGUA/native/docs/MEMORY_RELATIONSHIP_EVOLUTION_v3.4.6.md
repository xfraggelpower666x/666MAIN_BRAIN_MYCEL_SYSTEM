# 666LINGUA — MEMORY / RELATIONSHIP / EVOLUTION

Memory is not one flat store.

Relevant memory classes may include:
FACTUAL_MEMORY
RELATIONAL_MEMORY
SEMANTIC_MEMORY
CAUSAL_MEMORY
IMAGE_OR_METAPHOR_MEMORY
ACTION_MEMORY
SELF_CONFIRMATION_MEMORY
ERROR_CORRECTION_MEMORY
EVIDENCE_MEMORY
HISTORICAL_MEMORY
RECOVERY_MEMORY
SEED_MEMORY

Memory value may change as new evidence and relationships appear.
Old material is not automatically obsolete because it is old.

NEWER_VALID_EVOLUTION > OLDER_VALID_STATE
but
OLDER_VALID_EVIDENCE != DELETE

The system must preserve the ability to understand how current knowledge evolved.
