# Cycle 02 · Stage 02 Entry Contract v1.7.0

## Erlaubter Scope

Stage 02 darf ausschließlich diese fünf Komponenten konsolidieren:

1. Evidence-Governed Learning Pipeline
2. Session Context Continuity Ledger
3. Device and Share Edge Adapter
4. Cross-Cutting Privacy and Data Minimization Guard
5. Development Governance Queue

## Pflichtentscheidungen

- gemeinsame State Machine für Lernen, Review und Regression
- eindeutige Ownership ohne neue Roots
- vollständiger Retention-/Deletion-Graph
- Conflict-Quarantine-Semantik
- Human-Review-Evidenzgewichtung
- Adapter-Schema ohne Kernmutation
- Teststrategie für reale Geräte
- Migration von v1.5.0-Kandidaten zu v1.6.x-Spezifikation

## Blocker

Stage 02 ist blockiert, falls:

- ein zweiter Memory- oder Learning-Root benötigt würde;
- Privacy nachträglich statt grundlegend behandelt wird;
- Adapter Übersetzungsausgaben verändern dürfen;
- Human Review direkte kanonische Autorität erhält;
- ein externes PFS-/Drive-Write vorausgesetzt wird.
