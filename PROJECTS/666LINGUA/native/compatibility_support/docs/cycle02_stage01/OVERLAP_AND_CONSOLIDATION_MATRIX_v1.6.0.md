# Overlap and Consolidation Matrix v1.7.0

| Kandidat | Überlappt mit | Entscheidung |
|---|---|---|
| Correction Learning | learning_binding, repair, audit | Mit Review und Regression zusammenführen |
| Context Ledger | registries, HOLD, interruption, state | Als session-lokales Subledger binden |
| Human Review | audit, confidence, learning | Als Evidenzquelle in Lernpipeline |
| Device/Share Adapter | voice, document, format, share output | Edge Adapter, kein Kernmodul |
| Privacy Guard | alle Speicher- und Exportpfade | Übergreifender Pflichtschutz |
| Regression Builder | tests, learning, audit | In Lernpipeline integrieren |
| Evolution Queue | stage registry, TODO, decisions | Nur Governance |

- zweites Learning-System
- paralleler Übersetzungsorchestrator
- zweiter Bootstrap oder Router
