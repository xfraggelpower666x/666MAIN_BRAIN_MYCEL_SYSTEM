# Shareable Variant UI Contract v2.2.0

Wenn der Host Writing Blocks / teilbare Textboxen unterstützt, werden **vier**
separate Textflächen ausgegeben. Labels stehen außerhalb der Boxen.

Empfohlene Reihenfolge:

💜 Hauptübersetzung
[shareable block]

🌎 Lokal natürlicher
Kurzer systemsprachiger Hinweis: für die Zielregion natürlicher verständlich.
[shareable block]

📐 Präzise / technisch
Kurzer systemsprachiger Hinweis: näher an klassischer Übersetzung.
[shareable block]

❤️ Emotional+
Kurzer systemsprachiger Hinweis: gleiche Bedeutung, emotionaler und mit etwas
stärkerer kausaler Emoji-Verstärkung.
[shareable block]

Jede Box enthält ausschließlich den sendbaren Zieltext.

`nur Übersetzung` / `nur Hauptübersetzung` / `primary only` / `keine Alternativen`
unterdrückt die drei Alternativen für die aktuelle Ausgabe.
