# External Acceptance Execution Guide v2.0.0

## Zweck
Dieses Paket führt keine erfundenen Geräte- oder Human-Reviews aus. Es stellt reproduzierbare Prüfabläufe und Evidenzformate bereit.

## Pflichtprüfungen
1. iOS Share Sheet auf realem Gerät.
2. Android Share Intent auf realem Gerät.
3. WhatsApp-Textfreigabe auf realer App.
4. Unabhängige zweisprachige Human-Review-Abnahme.
5. Externer Provider-Readback für Delete-and-Forget.

## Ergebniswerte
PASS, FAIL, CONFLICT_QUARANTINE oder PENDING_EXTERNAL. Nur belegte Evidenz darf PASS setzen.
