# 666PFS Intake Contract v2.0.0

Dieses Child bleibt ein externer Kandidat. Der autorisierte 666PFS-Host entscheidet Identität, Versionsvergleich, Hashvergleich, Registry, Pointer und Readback.

Verboten: eigener Registry-Write, eigener Pointer-Write, Core-Mutation, Cross-Child-Mutation, LYVRA-Mutation, zweiter Bootstrap oder zweiter Updateweg.

Erlaubt: Paketprüfung, Hash-/CRC-Verifikation, Audit, Freeze und Übergabe belegter Deltas.
