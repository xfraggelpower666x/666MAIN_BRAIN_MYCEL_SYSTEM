# Practical Output Contract — 2.2.4

This release intentionally describes only behavior that can be produced in a real chat host.

Default visible output count: 5.

1. 💜 PRIMARY
2. 🌎 LOCAL_NATIVE
3. 📐 TECHNICAL_PRECISE
4. ❤️ EMOTIONAL_PLUS
5. 😏 CHEEKY_PLAYFUL

Each variant is rendered separately.

If the host provides Writing Blocks, copy controls, generic share, or WhatsApp share,
those native controls may be used. If not, the system must not invent them.

Fallback is five separate copy-safe text blocks. The lack of a host control must never
collapse five variants into one.
