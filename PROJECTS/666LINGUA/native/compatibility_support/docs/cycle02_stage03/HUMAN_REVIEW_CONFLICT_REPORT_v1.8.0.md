# Human Review Conflict Report v1.8.0

User-Korrekturen besitzen höchste fachliche Autorität. Gleichrangige widersprüchliche User-Claims werden nicht geraten, sondern in CONFLICT_QUARANTINE gehalten. Ein niedrigerer Evidenzrang kann einen höheren Rang niemals überschreiben. Eine unabhängige zweisprachige Human-Acceptance-Prüfung bleibt für Stage 04 offen.
