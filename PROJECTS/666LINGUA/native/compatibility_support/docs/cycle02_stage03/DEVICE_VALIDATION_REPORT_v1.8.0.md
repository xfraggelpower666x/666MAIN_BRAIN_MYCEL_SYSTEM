# Device Validation Report v1.8.0

Vier deterministische Adapter-Fixtures wurden ausgeführt: iOS Share Sheet, Android Share Intent, WhatsApp Text Share und generische Zwischenablage. In allen Fällen wird ausschließlich der finale sichtbare Text exportiert. Hidden Metadata, Rohinput, Ledger- und Lerninformationen bleiben ausgeschlossen. Share-Fehler verändern den Text nicht.

Echte Hardware-/App-Tests bleiben als externe Akzeptanzprüfung offen und werden nicht als durchgeführt behauptet.
