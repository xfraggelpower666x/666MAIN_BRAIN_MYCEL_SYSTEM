# Delete-and-Forget Test Report v1.8.0

Die isolierte Runtime löscht alle Einträge einer angeforderten Lineage und lässt unabhängige Lineages unverändert. Das Ergebnis enthält requested/deleted/complete und erlaubt damit einen überprüfbaren Readback. Persistente Provider- oder Host-Speicher außerhalb des Pakets wurden nicht getestet.
