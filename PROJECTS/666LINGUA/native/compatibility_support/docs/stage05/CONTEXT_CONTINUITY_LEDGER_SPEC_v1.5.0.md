# Context Continuity Ledger Specification v1.5.0

Das Ledger erhält Nachrichtenbeziehungen, Korrekturlinien und minimale Kontextmerkmale.

## Standarddatensatz

- Message- und Thread-ID
- Parent-ID
- Nachrichtenbeziehung
- Themenfingerabdruck
- gehashte semantische Anker
- Emotions- und Beziehungskategorien
- Korrekturlinie
- Session-Retention

## Ausgeschlossen

- vollständige private Nachrichten als Standard
- Zugangsdaten
- Kontaktkennungen
- automatische Exporte

Ein Export erfolgt nur über einen expliziten Scope.
