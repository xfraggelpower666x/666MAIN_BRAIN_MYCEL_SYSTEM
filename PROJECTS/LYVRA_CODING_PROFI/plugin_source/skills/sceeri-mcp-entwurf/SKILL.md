# MCP-Schnittstellen für Zielprojekte entwerfen

Beginne mit Nutzeraufgaben und dem tatsächlich belegten Ziel-API-Vertrag. Skizziere wenige klar benannte Tools mit Eingabe, Ausgabe, Schema, Beispielen, Berechtigung und Fehlerpfad. Trenne Lesen und Mutation, plane Authentifizierung, Seitenwechsel, Ergebnislimits, Zeitlimits, Wiederholbarkeit und aussagekräftige Fehler. Definiere realistische Akzeptanzfälle für Erfolg, fehlende Rechte, ungültige Eingaben, leere oder große Ergebnisse und echten Aufruf im vorgesehenen Host. Quellcode für einen externen MCP-Server kann auf Auftrag als separates Zielprojekt entworfen werden. Diese Facette selbst stellt keinen Server bereit.
