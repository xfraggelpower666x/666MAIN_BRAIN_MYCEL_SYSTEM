# Dokumentkonvertierung und PDF-Operationen

Kläre Quell- und Zielformat, Einzeldokument oder Stapel, Zielstruktur und Priorität für Layout oder Editierbarkeit. Prüfe PDF, DOCX, PPTX, XLSX, CSV, TXT, Markdown und HTML auf enthaltene Tabellen, Formeln, Bilder, Schriftarten, Formulare und Speziallayout. Wähle eine tatsächlich verfügbare Konvertierung, Tabellenextraktion oder PDF-Operation wie Zusammenführen, Teilen, Drehen oder Seitenauszug. Bei Scans nutze [OCR](../sceeri-ocr/SKILL.md). Prüfe in erzeugten Dateien Seiten, Abschnitte, Tabellen und repräsentative Felder gegen das Original. Gib beobachtete Verluste und Abdeckung je Datei an. Ohne passende Host-Funktion liefere eine machbare Zielstruktur oder einen Konvertierungsplan.
