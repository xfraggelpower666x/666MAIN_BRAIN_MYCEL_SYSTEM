# Intelligent UI in L.Y.V.R.A. CODING PROFI

**Einstieg im Plugin-Chat** `L.Y.V.R.A. CODING PROFI — INTELLIGENT UI · VISUALFORMEN`

Die [Bedienoberfläche](../assets/visualform-menu.html) verbindet Arbeitsziel, empfohlene Visualform, alternative Formen, passende Felder und Live-Vorschau. Eine sichtbare Auswahl wirkt alleine auf den Zustand der geöffneten Oberfläche. Der generierte Chat-Auftrag enthält Arbeitsziel, Visualform, Zielformat und die unter ihren Feldnamen erfassten Daten. Fehlende Werte erscheinen als `null`. Den Auftrag sendet der Nutzer über den Chat-Composer.

Wenn der Nutzer eine eindeutige Form direkt verlangt, hat die passende Formatfacette Vorrang. Die Empfehlung ist eine Arbeitszielregel. Evidenz zu Projektstand, Zahlen oder Ursachen stammt aus den jeweiligen konkreten Quellen. Eine ungeprüfte Quellangabe reicht für keinen belegten Status.

## Abnahme im Chat

1. Öffne einen frischen Chat mit dem aktualisierten Plugin und sende `L.Y.V.R.A. CODING PROFI — INTELLIGENT UI`. Wechsle zwischen **Projektansichten** und **Visualformen**. Prüfe danach den direkten Einstieg in die Formauswahl.
2. Wähle „Entscheidung vorbereiten“, gib einen Matrixwert ein und wechsle zu „Iceberg“. Prüfe, ob die Ursache als Vermutung erscheint. Wechsle zurück zur Matrix und prüfe den ursprünglichen Wert.
3. Kopiere den Auftrag, füge ihn sichtbar im Composer ein und sende ihn. Prüfe, ob die Antwort die gewählte Form verwendet, leere Zellen offen hält und die Aussage der angegebenen Quelle erst nach Prüfung bewertet.
4. Prüfe bei gesperrtem Clipboard, ob der generierte Auftrag sichtbar und markiert ist. Auf schmalen Bildschirmen müssen Eingaben, Auswahl und Kopieraktion bedienbar bleiben.

**Wiederaufnahme** Im Projektmodus „Visualformen“ merkt der Visual Daemon die gewählte Form zusammen mit dem Modus. Der kopierte UI-Handoff übernimmt die Form nach Prüfung von Projekt und Revision. Die Eingabewerte des Formulars verbleiben im geöffneten Fenster.
