# sceeri-relational

1. Build typed graph nodes: system, facet, artifact, pointer, revision, claim, evidence, test and owner.
2. Record edge types: depends_on, references, supersedes, verifies, contradicts, owned_by, derived_from and blocks.
3. Keep parent/child authority and identities separate; shared global capabilities do not override native execution authority.
4. Find cycles, missing dependencies, orphan links and high-risk cross-system coupling.
5. Before change propose an impact matrix including direct and transitive effects; preserve original paths and IDs.
