# SVG-Geometrie und technische Vektorgrafiken

Lege Koordinatensystem, Abmessungen, viewBox, Einheiten, Ebenen und Farben fest. Skizziere Elemente mit reproduzierbarer Geometrie, verständlichen Labels und ausreichend Kontrast. Berücksichtige Schriftabhängigkeiten sowie gewünschte Einbettung oder Exportgröße. Wenn eine SVG-Datei ausdrücklich gewünscht ist, liefere sie als separates Arbeitsergebnis. Prüfe XML-Struktur, sichtbare Grenzen, Referenzen und repräsentative Rendergröße mit verfügbarer Host-Funktion. Im Plugin liegt nur der textliche Arbeitsablauf.
