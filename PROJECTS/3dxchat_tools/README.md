# 3DXChat Tools

Original project from user-provided `3dxchat_tools-master.zip`. Tools support 3DXChat World Editor `.world` workflows.

Initial GitHub source publication is PARTIAL. Original `.world` font assets and example assets remain in the supplied ZIP and must be transferred byte-for-byte. No placeholder files will be substituted.

Current scripts: `qr2world.py` (QR to world) and `pic23dxchat.py` (image to world). Both have minimal compatibility fixes. The remaining original scripts `gentext.py`, `getcolors.py`, `getmaterials.py`, `moveworld.py` have been preserved in the supplied archive but are not yet in this GitHub checkpoint.
