DTSTE__HANDOFF__v0_FULL.txt

PACKAGE ROLE
This file explains how the stack is used in a new chat and what each file does.
It is an operator sheet and handoff route, not a lyrical system component.

STACK FILE ORDER

1. DTSTE__CORE__v0_FULL.txt
Central route law, state basis, system hierarchy, output protocol.

2. DTSTE__DNA__v0_FULL.txt
Identity streets, special words, phonetics, 666 logic, signature behavior.

3. DTSTE__DJ_MASTERING__v0_FULL.txt
DJ safety, club mastering, Suno routing, prompt limits, practical constraints.

4. DTSTE__VARIATION_MEMORY_ANTI_AI__v0_FULL.txt
Variation, anti-clone behavior, anti-AI behavior, session memory logic.

HOW TO LOAD IN A NEW CHAT

Method A
Paste files in order, one after another, full content each.
After all files are loaded, send:
RUN SYSTEM
Theme: ...

Method B
If the model supports reading long files in one context, upload all four and instruct:
Use all attached DTSTE system files as one stack. Do not summarize. Do not rewrite. Execute as system.

IMPORTANT OPERATOR RULES

Do not paste only the DNA file and expect full function.
Do not paste only the variation file and expect identity.
Do not mix order if avoidable.
Do not ask the model to “summarize the files first.”
Do not let the model rewrite the files into smaller “better” versions before use.
Do not trust the model to reconstruct deleted system streets from memory if key files were omitted.

HOW TO WORK PRACTICALLY

For new track build:
load stack
then provide:
- theme
or
- 2–3 words
or
- full lyrics
or
- lyrics + style + advanced instructions
or
- audio references if supported in that environment

Then instruct:
Build track in 4-box format.

If specific Suno version differs from default:
state it before build.

If you want to preserve recent variation logic:
paste previous outputs or summarize recent tracks to seed session memory.

WHY THIS STACK EXISTS

Because a real system is not one tiny prompt.
Because removing streets breaks routes.
Because identity, routing, DJ safety, and anti-generic logic live in different districts.
Because modular transport is safer than one overcompressed blob.
