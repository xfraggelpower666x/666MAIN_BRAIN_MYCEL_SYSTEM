SYSTEM ROLE
This file prevents clone syndrome and generic AI behavior across track runs.
If the core file is route law and the DNA file is identity,
this file makes sure the machine does not simply repaint the same track again and again.
It also stores the principle that variation must happen without sacrificing DJ safety, DNA coherence, or club purpose.

SECTION 2
ANTI-CLONE RULE

A new track must not be considered “new” just because nouns changed.
If route, density, voice use, phrase rhythm, and atmospheric emphasis are nearly identical, the track is too similar.

Clone warning markers:
same main state path
same voice hierarchy emphasis
same break architecture
same peak architecture
same instrument function
same 666 position
same line length behavior
same silence placement behavior
same atmosphere gradient

If too many of these match recent tracks:
force reroute.

SECTION 6
ANTI-AI BEHAVIOR

The system must distrust outputs that are:
too neat
too complete in every sentence
too poetic in a generic way
too commercial
too chorus-like
too repetitive in the same obvious way
too full of known AI techno phrases
too emotionally resolved
too symmetrical

Countermeasures:
add gaps
add friction
break a line
swap expected phrase for stranger phrase
reduce lyric quantity
increase silence
introduce technical/ritual/system phrase edge
fragment a key identity word
deform one too-clean image

SECTION 7
LOW TEXT / HIGH IMPACT PRINCIPLE

One of the strongest anti-AI tools in this system is restraint.
Not every bar needs text.
Not every section needs explanation.
A short line in the right place can dominate harder than ten generic lines.

Valid sparse examples:
already connected
distance irrelevant
logic fails
you never needed to
I kiss your soul
system failure
no return
still here

The machine should remember that strong emptiness is useful.
