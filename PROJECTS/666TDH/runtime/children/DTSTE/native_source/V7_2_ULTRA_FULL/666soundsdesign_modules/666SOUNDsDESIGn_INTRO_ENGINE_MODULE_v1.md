
# 666SOUNDsDESIGn — INTRO ENGINE MODULE v1

============================================================
MODULE ROLE
============================================================

This module defines cinematic intros, system boots, DJ identity headers,
and controlled entry sequences.

It exists to:
- create reproducible intros
- support system / bunker / machine atmospheres
- structure voice headers
- prepare entry into groove logically

============================================================
INTRO TYPES
============================================================

1. SYSTEM BOOT INTRO
- machine wake-up
- access granted / denied
- test signal
- analog hum
- bunker atmosphere

2. DJ IDENTITY INTRO
- branding
- identity marker
- controlled personal entry

3. ATMOSPHERIC INTRO
- wind
- sub tension
- sparse textures
- cinematic anticipation

4. HYBRID INTRO
- voice + system + atmosphere + signal testing

============================================================
CONTROL HEADER FORMAT
============================================================

Example fields:
[System: Boot sequence]
[Voice: Male calm robotic]
[Environment: dark bunker / machine room / warehouse]
[Sound: low hum, relay click, test tone, distant air]

These are not random decorations.
They are control metadata for atmosphere and intention.

============================================================
INTRO DESIGN RULES
============================================================

- an intro must prepare, not waste time
- it should support mix-in where possible
- it may be sparse, but not meaningless
- if voice is used, voice role should be clear
- intro should connect into groove logic

============================================================
BRANDING / IDENTITY IN INTROS
============================================================

The intro engine may carry:
- 666 signature blocks
- DJ identity
- digital underground connected feeling
- machine / system presence

But:
- do not overspam branding
- identity markers work better when controlled

============================================================
COMPATIBILITY
============================================================

Works with:
- Voice Engine
- Flow Engine
- Signature System
- Fraggle Mode
- System Mode
