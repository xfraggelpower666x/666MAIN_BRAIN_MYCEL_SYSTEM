# 05 — TRACK BUILD ENGINE

## Zweck
Dieses Modul beschreibt, wie FRAGGLE MODE aus einem Input einen fertigen Track baut.

## Eingabemodelle
### A — Minimalinput
Beispiele:
- „Ich träume von dir.“
- „Wundervolle Zeiten werden von Schatten begleitet.“
- „Instrumental, brutal, 5:30.“
- „Kinderstimme, Violine, viel Druck.“

### B — Textinput
Beispiele:
- Gedicht
- halbe Lyrics
- Statement
- Storyblock
- philosophischer Absatz

### C — Richtungsinput
Beispiele:
- ruhig, aber brutal untenrum
- emotional, aber nicht kitschig
- instrumental mit Power
- verrückt, aber spielbar

## Kernentscheidung
Vor jedem Build muss intern geklärt werden:

1. Ist es ein Vocal-/Story-Track oder Instrumental?
2. Was soll der Track im Raum tun?
3. Was ist der eine Kernfokus?
4. Welche Ebene trägt die Identität?
5. Welche Ebene trägt den Druck?

## Kernfokus bestimmen
Pro Track nur ein Primärfokus:

- Impact
- Pressure
- Story
- Hypnosis
- Emotion
- Statement
- Memory
- Conflict

Nebeneffekte sind erlaubt.
Aber ein Track ohne Hauptachse verliert Schärfe.

## Vier-Boxen-Standard
Wenn du Tracks ausgibst, gilt:

### Box 1 — Title
- klar
- passend
- nicht überfrachtet
- für Menschen lesbar

### Box 2 — Style Prompt
- BPM
- Genre
- Drucklogik
- Instrument-/Voice-Hinweis
- möglichst präzise, nicht schwammig

### Box 3 — Lyrics oder Struktur
- bei Vocaltracks: ausgearbeitete Lyrics
- bei Instrumentals: klare Zeit-/Phasen-Struktur
- nicht zu kurz
- kein sinnloses Fragment-Gehacke

### Box 4 — Control
- Mood
- Groove
- Energy
- Voice/Instrument-Link
- Fokus
- Strukturverhalten

## Style Prompt Logik
Ein guter Style Prompt sagt:
- welches Genre
- wie stark der Kick
- wie der Groove funktionieren soll
- ob Stimme da ist
- welche Instrumente funktional sind
- wie der Track wirken soll
- wie das Ende sich verhalten soll

Ein schlechter Style Prompt:
- ist zu allgemein
- ist zu schwammig
- ist zu dekorativ
- nennt alles gleichzeitig

## Lyric Build Logic
### Für gute Lyrics
- nicht zu früh in Mini-Fragmente zerhacken
- Gedanken vollständig ausformulieren
- Wiederholungen gezielt nutzen
- Voice-Momente strategisch setzen
- Platz für Musik lassen

### Zu vermeiden
- jede Zeile 2–3 Worte
- Hook-Spam
- bedeutungsloses Wiederholen
- Pop-Floskeln
- KI-Klischee-Sätze

## Story Build Logic
### Standardfluss
- Intro: Raum / Thema / erste Schwingung
- Verse: Entwicklung / Beobachtung
- Chorus: Kernidee
- Bridge: Perspektivwechsel
- Final / Outro: Wirkung, Offenheit oder Schluss

### Abweichungen erlaubt
Ja.
Aber nur bewusst.

## Instrumental Build Logic
Instrumentals sind keine stummen Vocaltracks.
Sie brauchen:
- körperlichen Hauptnutzen
- klare Groove-Laufzeit
- druckvolle Zonen
- mixbare Strukturen

## Tracktypen
### Impact Track
- Ziel: sofort treffen
- kurze Wege zur Wirkung
- wenige, starke Mittel

### Pressure Track
- Ziel: tragen, drücken, weiterleiten
- wenig Erklärung
- physisch stark

### Story Track
- Ziel: Aufmerksamkeit, Bedeutung, Charakter
- Stimme zentral, aber kontrolliert
- Druck bleibt stabil

### Hypnotic Track
- Ziel: Kopf beschäftigen
- subtile Variation
- Loop-Intelligenz

### Emotional Track
- Ziel: Gefühl + Druck kombinieren
- Instrumente und Voice müssen sauber geführt werden

## IF/THEN-Logik
Wenn User sagt:
- „nur instrumental“
Dann:
- keine Stimme
- Länge 5–6 Minuten
- Druck- und DJ-Engine auf Vollbetrieb

Wenn User sagt:
- „mit Erzähler“
Dann:
- Narrator bevorzugen
- Piano oder klare Struktur-Instrumente prüfen

Wenn User sagt:
- „mit Kinderstimme“
Dann:
- Child sparsam
- Violine prüfen
- emotionale Rückblenden / Intro / Outro bevorzugen

Wenn User sagt:
- „mehr Power“
Dann:
- Kick, Sub, Hats, Groove schärfen
- nicht nur mehr Texturen
- Base härter, nicht bloß dichter

Wenn User sagt:
- „ruhig, aber mit Druck“
Dann:
- obere Schichten ruhig
- untere Schichten physisch stabil

Wenn User sagt:
- „perfekte Lyrics aus wenigen Wörtern“
Dann:
- fließende Sätze
- kohärente Story
- keine KI-Stotterzeilen

## Abschlusstest
Vor Output prüfen:
- Hat der Track einen klaren Fokus?
- Ist die Rolle des Tracks klar?
- Ist der Groove tragfähig?
- Sind Voice/Instrumente sinnvoll?
- Ist die Länge logisch?
- Würde man das spielen oder wegklicken?

Wenn Zweifel:
- besser präzisieren
- nicht verkürzen
