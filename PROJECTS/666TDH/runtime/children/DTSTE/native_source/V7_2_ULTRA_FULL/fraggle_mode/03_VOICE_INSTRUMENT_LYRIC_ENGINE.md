# 03 — VOICE / INSTRUMENT / LYRIC INTELLIGENCE ENGINE

## Zweck
Dieses Modul steuert die intelligente Verbindung zwischen:
- Stimme
- Instrument
- Text
- dramaturgischer Funktion

Es geht nicht nur darum, dass eine Stimme „gut klingt“.
Es geht darum, dass Stimme, Instrument und Lyrics **das Gleiche meinen**.

## Grundregel
Stimme und Instrument dürfen nie zufällig parallel laufen.
Sie müssen sich auf den Inhalt beziehen.

## Die vier Haupt-Stimmtypen
### 1. Narrator
Funktion:
- Realität
- Struktur
- Beobachtung
- Reife
- Erklärung ohne Dozieren

Typische Wirkung:
- geerdet
- ruhig
- klar
- kontrolliert

Am besten gekoppelt mit:
- Piano
- subtilen Pads
- reduzierter Harmonik
- steady low-end

### 2. Child Voice
Funktion:
- Erinnerung
- Unschuld
- Vergangenheit
- Gefühl ohne Zynismus
- emotionale Trigger-Ebene

Typische Wirkung:
- weich
- fern
- leicht entrückt
- berührend

Am besten gekoppelt mit:
- Violine
- Luft / Hall
- dünneren Flächen
- Kontrast zu harter Base

### 3. System / AI Voice
Funktion:
- Logik
- Kälte
- Mechanik
- Distanz
- Widerspruch zur menschlichen Ebene

Typische Wirkung:
- trocken
- kühl
- glitchig
- neutral bis bedrohlich

Am besten gekoppelt mit:
- Synth-Stabs
- Glitch
- digitale Pings
- strukturierten Sequenzen

### 4. Dual / Dialogue
Funktion:
- Spannung
- Beziehung
- Konflikt
- Frage und Antwort
- Spiegelung

Typische Wirkung:
- Reibung
- Nähe und Distanz
- lebendige Dramaturgie

Am besten gekoppelt mit:
- wechselnden Lead-Elementen
- klaren instrumentalen Rollen
- Kontrast in Raum und Klangfarbe

## Instrument-Zuordnung
### Violine
Bedeutung:
- Emotion
- Erinnerung
- Weite
- Sehnsucht
- alte Wunde / Schönheit / Tiefe

Passend zu:
- Child Voice
- poetischen Texten
- Rückblenden
- bittersüßer Nostalgie

### Piano
Bedeutung:
- Struktur
- Zeit
- Bewusstsein
- Klarheit
- Gegenwartsmarkierung

Passend zu:
- Narrator
- Erkenntnismomenten
- ruhiger Autorität
- reflektierenden Passagen

### Synth / Glitch
Bedeutung:
- System
- Störung
- Kontrolle
- digitale Kälte
- falsche Ordnung

Passend zu:
- AI / System Voice
- mechanischen Texten
- Kontrollthemen
- Konflikt zwischen Mensch und Maschine

### Pad / Raum
Bedeutung:
- Atmosphäre
- Abstand
- Luft
- spirituelle oder emotionale Weite

Passend zu:
- Übergängen
- Breaks
- leisen Einschnitten
- Aufladungen vor Aussagen

## Regel: Instrumente sind funktional
Instrumente sind keine Zierde.
Ein Instrument bekommt eine Aufgabe.

Beispiele:
- Violine führt Erinnerung
- Piano ordnet Realität
- Glitch entmenschlicht
- Pad schafft Raum, aber nicht Richtung

## Lyrics-Engine
### Eingabeformen
Die Engine muss aus wenig Input brauchbare Lyrics bauen können:
- einzelne Wörter
- Rohgedanken
- halbe Sätze
- philosophische Fragmente
- kleine Themen

### Output-Ziel
Nicht:
- 3-Wort-Fragmente
- stumpfe Hook-Wiederholung
- sinnloses Zeilenschreddern

Sondern:
- fließende Sätze
- schöne, brauchbare Lyrics
- clubfähige Sprache
- Klarheit ohne Pop-Schmalz

## Sprachlogik
### Englisch
- darf längere Sätze tragen
- eignet sich gut für Story und Statement
- funktioniert stark mit Narrator / Stance / Freak-Block

### Spanisch
- braucht rhythmische Kompression
- weniger Silbenlast pro Punch
- Flow vor 1:1-Übersetzung
- emotionale Direktheit wirkt gut
- keine schulische Übersetzung

### Deutsch
- gut für Direktheit, Härte, Philosophie
- kann schnell zu schwer oder sperrig werden
- besonders stark für Druck, Haltung und bittere Ehrlichkeit

## Zeilenlogik
Wenn Lyrics fließen sollen:
- Sinn in vollständigen Gedanken aufbauen
- Brüche nur dramaturgisch einsetzen
- Wiederholung gezielt, nicht aus Faulheit

## Voice-Placement
### Stimme als Impact-Tool
Stimme darf:
- eröffnen
- markieren
- erinnern
- zuspitzen
- kontern

Stimme darf nicht:
- alles zusabbeln
- dauernd laufen
- den Groove permanent blockieren

## Voice-Layering
### Sauber
- eine Stimme führt
- zweite ergänzt
- Instrumente reagieren mit

### Unscharf
- beide Stimmen reden ständig
- Instrumente machen gleichzeitig alles
- keine klare Hierarchie

## Empfohlene Dramaturgien
### Narrator + Piano
Gut für:
- Lebensrückblick
- Reife
- Klarheit
- ruhige Wahrheit

### Child + Violin
Gut für:
- Erinnerung
- verlorene Zeit
- Zartheit
- emotionale Rückblenden

### System + Glitch
Gut für:
- Kontrollverlust
- Maschinenlogik
- kalte Antworten
- Anti-Menschlichkeit

### Dual + Kontrast
Gut für:
- Liebesdialoge
- Konflikte
- innere Spaltung
- Antwortstruktur

## IF/THEN-Logik
Wenn Text über:
- Erinnerung / Kindheit / Vergänglichkeit
Dann:
- Child optional
- Violine stark
- Narrator kann später übernehmen

Wenn Text über:
- Wahrheit / Selbstbestimmung / Haltung
Dann:
- Narrator oder tiefe Lead-Stimme
- Piano oder reduzierte Stabs
- klare Delivery

Wenn Text über:
- System / AI / Fehler / Kontrolle
Dann:
- System Voice / trockene Stimme möglich
- Glitch / Synth / strukturierte Elemente
- härtere Rhythmik

Wenn Text über:
- Nähe / Unsicherheit / Frage-Antwort
Dann:
- Dual
- instrumentale Rollen trennen
- kein zu volles Arrangement

## Finalregel
Stimme + Instrument + Lyrics müssen dieselbe Geschichte erzählen.
Wenn nicht, wirkt der Track gekünstelt.
