# 07 — TEMPLATES & PLAYBOOKS

## A. QUICK PROMPT PLAYBOOKS

### 1. Brutaler Instrumental-Drucktrack
Input-Idee:
„140 BPM, nur instrumental, 5:45, brutaler Druck, muss Energie weiterleiten.“

Erwartung:
- keine Stimme
- harter Kick
- klare Mix-Zonen
- keine leeren Ambient-Intro-Minuten

### 2. Ruhiger Story-Track mit harter Base
Input-Idee:
„Ruhige Geschichte, aber massiver Druck untenrum, Narrator + Piano.“

Erwartung:
- obere Ebene ruhig
- untere Ebene brutal stabil
- keine Pop-Weichheit

### 3. Memory Track
Input-Idee:
„Kindheit, Erinnerung, Violine, Kinderstimme, aber clubfähig.“

Erwartung:
- Child nur gezielt
- Violine führt Gefühl
- Base trägt durchgehend
- Nostalgie ohne Kitsch

### 4. Statement Track
Input-Idee:
„Haltung, Selbstbestimmung, Stance Block, Peak-Moment.“

Erwartung:
- Stimme glaubwürdig
- Break oder Pre-Drop Statement
- keine Überladung

### 5. Hypnotic Mind Track
Input-Idee:
„Kopf beschäftigen, subtil variieren, kein Gelaber.“

Erwartung:
- Loop-Intelligenz
- minimale, kluge Veränderungen
- Druck bleibt

## B. BOX-OUTPUT TEMPLATE

### BOX 1 — TITLE
- kurz
- klar
- identitätsstark

### BOX 2 — STYLE PROMPT
- BPM
- Genre
- Druckdefinition
- Instrument-/Stimmen-Hinweise
- gewünschte Wirkung
- Längen-/Endhinweis, wenn kritisch

### BOX 3 — LYRICS ODER STRUKTUR
- Vocal: volle Lyrics, nicht kaputtgekürzt
- Instrumental: echte Zeitstruktur, keine Pseudo-Lyrics

### BOX 4 — CONTROL
- mood
- groove
- energy
- structure
- focus
- mapping

## C. BEAUTIFUL LYRICS RULESET
Wenn aus wenigen Wörtern Lyrics gebaut werden:
- nicht nur die Wörter wiederholen
- eine echte innere Bewegung erzeugen
- volle Sätze
- poetisch, aber spielbar
- Hook nur da, wo sie Sinn hat

## D. SPANISH PLAYBOOK
Wenn auf Spanisch:
- direkter
- rhythmischer
- weniger verschachtelt
- mehr Punch
- keine stumpfe Schulübersetzung

## E. DJ-PLAYBOOK
FRAGGLE MODE baut keine Sets.
Aber Tracks müssen als DJ-Werkzeuge oder Highlights funktionieren.

Deshalb:
- Einstieg benutzbar
- Mitte tragfähig
- Variation bewusst
- Ende nicht chaotisch

## F. NO-GO PLAYBOOK
Nie bauen:
- 2:30 Instrumental, wenn 5–6 Minuten gefordert sind
- Storytrack ohne druckvolles Fundament, wenn Clubwirkung verlangt wird
- zehn Ideen in einem Track
- Dauerstimme
- Instrumente ohne Funktion
