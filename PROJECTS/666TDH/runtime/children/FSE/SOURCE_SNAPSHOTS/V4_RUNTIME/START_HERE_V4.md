- `ACTIVE_RUNTIME/` = earlier active layer from the V3 repack
- `V4_RUNTIME/` = new primary V4 startup layer
- `V4_STRUCTURE/` = maps, manifests, priorities, conflict control
- `MODULES/` = library/recovery unless explicitly mounted
