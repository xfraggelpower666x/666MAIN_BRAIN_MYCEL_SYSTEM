## What LCTS builds
LCTS targets continuous 10–20+ minute tracks created through Base + one or more Extend stages + Whole Song cycles + Final Stage.

LCTS does not treat extensions as separate songs. Every accepted stage must preserve the same track identity, low-end motor, temporal frame and developmental memory.

## Typical workflow
1. Define Track Manifest and Continuity State.
2. Build Stage A / Base.
3. Review real audio.
4. Accept only if motor, identity and continuation zone hold.
5. Extend from a prepared stable anchor.
6. Review transition before Get Whole Song.
7. Update Continuity State after every accepted stage.
8. Repeat as needed.
9. Use Final Stage only when the target journey is ready to converge.
10. Audit the final Whole Song as one composition and as a DJ object.
