# Recovery Guide

LCTS recovery does not depend on chat memory.

## Required recovery set
Minimum:
1. `SYSTEM_IDENTITY.md`
2. `OPERATING_MODEL.md`
3. `LONGFORM_COMPOSITION_MODEL.md`
4. `CONTINUOUS_MOTOR_MODEL.md`
5. `SUNO_EXTEND_WORKFLOW.md`
6. prompt templates
7. current `TRACK_MANIFEST.md`
8. current `CONTINUITY_STATE.md`
9. current `EXTEND_MAP.md`
10. latest accepted `STAGE_REVIEW.md`

## Recovery sequence
1. Verify SYSTEM_ID and version.
2. Confirm this is LCTS, not normal Track Design.
3. Read Track Manifest.
4. Read current Continuity State.
5. Read latest Stage Review and Extend Map.
6. Identify latest verified Whole Song.
7. Reconstruct current motor, story, motifs and unresolved relation.
8. Continue only the next intended stage.
9. If latest audio/state mismatch is unresolved, HOLD and document rather than guessing.

## Failure handling
If state files disagree:
`CONFLICT_QUARANTINE`
Do not silently choose the most convenient value.
