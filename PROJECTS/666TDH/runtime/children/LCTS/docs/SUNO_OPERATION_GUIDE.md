# Suno Operation Guide

## Before generation
Prepare:
- Track Manifest;
- Master Style;
- Base package;
- planned Continuation Zone.

## Base
Generate Stage A within the available Suno generation duration.
Do not instruct Suno to “make an 18-minute song”.
The 18-minute result will be constructed through stages.

## Selecting a Base
Prefer the render with the strongest:
1. motor stability;
2. identity;
3. continuation openness;
4. story fit.

A spectacular Base with a closing ending is a poor LCTS Base.

## Extend
Use the actual audio to find a stable open anchor.
Feed the current-stage package, not the whole handbook.

## Get Whole Song
Use only after extension + transition acceptance.
Then listen again to the combined file from before the join through after the join.

## Further Extend
Select the next anchor from the latest verified Whole Song, not from an obsolete earlier partial unless deliberately recovering.

## Final Stage
Mark Final Stage explicitly in Continuity State.
Only then ask for actual closure/outro/termination.
