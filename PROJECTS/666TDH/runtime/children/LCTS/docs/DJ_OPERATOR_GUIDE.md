# DJ Operator Guide

## What to listen for after every Whole Song
- Does the beat grid stay trustworthy?
- Do bass spacing and kick spacing remain constant?
- Does a transition create a hidden half-bar/one-bar displacement?
- Does the extension suddenly swing differently?
- Does low-end weight shift so hard it feels like Track 2?
- Can you count long phrases through dense psychedelic events?

## Mix-in
Prefer a Base with a readable entrance where the motor establishes before maximum semantic density.

## Mix-out
The final stage should intentionally create an exit region.
Do not mistake “quiet” for “mixable”.

## Practical acceptance
If you would hesitate to layer another 150 BPM track over the section because the low-end clock feels uncertain, mark `MIXABILITY_LOSS=REVIEW` even if the music sounds impressive.
