# Regeneration Policy

## If extension has unstable low end
Do not Get Whole Song.
Regenerate extension or choose a new anchor.

## If story is good but music restarts
Reject extension as continuity authority.
Reuse story intent, not the invalid audio.

## If music is excellent but sounds like Track 2
Reject for this LCTS track.

## If join is artificial
Status = REVIEW or REGENERATE_EXTENSION.
Do not promote merely to preserve effort.

## If anchor caused the problem
Status = ANCHOR_CHANGE_REQUIRED.
Move to a more neutral stable propulsion region.

## If only a small valuable element should survive
Document it in Stage Review as reusable idea.
Do not promote the entire extension.

## Repair ceiling
Prefer bounded regeneration/anchor changes over endless patching.
When repeated attempts fail, document `MANUAL_REPAIR_REQUIRED`.
