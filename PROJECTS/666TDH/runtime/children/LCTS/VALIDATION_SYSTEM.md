# Validation System

Validation is evidence-based and occurs after real renders.

## Stage validation

### Motor
- BPM stable?
- kick spacing stable?
- bass pulse stable?
- low-end relationship recognizable?
- bar/phrase readability retained?

### Identity
- same track?
- same core sonic world?
- extension feels developmental rather than introductory?

### Story
- current state continued?
- no premise reset?
- returning material transformed rather than copied?

### Transition
- no artificial seam?
- no intro restart?
- no unexpected end/start pair?
- no loudness or low-end discontinuity severe enough to break flow?

### Extend readiness
- continuation zone open?
- safe anchor exists?

## Final validation
- total arc coherent?
- final stage actually final?
- DJ entrance and exit usable?
- no hidden mid-track resets?
- whole-track identity preserved?
- final file/state/report versions agree?
