# Track Build Workflow

## Phase 0 — Initialize
Create:
- Track Manifest;
- Continuity State;
- Stage Map;
- initial Extend Map.

## Phase 1 — Base
Generate:
- title;
- master style;
- Base prompt;
- Base lyrics/structure;
- Continuation Zone plan.

Render multiple variants if useful.

## Phase 2 — Base Review
Listen for:
- motor stability;
- identity;
- story;
- continuation openness;
- DJ entry.

Only an accepted Base becomes State authority.

## Phase 3 — Extend
Choose GREEN anchor.
Build next stage from current State.
Render.
Review.
Reject reset/drift.

## Phase 4 — Whole Song
After accepted extension and join:
- Get Whole Song;
- review the combined track;
- update State;
- update Extend Map.

## Phase 5 — Repeat
Use additional stages only when the track still has meaningful developmental distance.

## Phase 6 — Final
Set `final_stage_planned=yes`.
Build final convergence from accumulated State.
Allow true semantic ending/outro/termination only here.

## Phase 7 — Final Report
Document:
- accepted stage chain;
- final runtime;
- final motor/identity;
- story resolution;
- DJ notes;
- known risks;
- final verification status.
