# Suno Extend Workflow

## Principle

Extend is part of composition design, not an emergency after the Base ends.

## Cycle

1. Generate Base.
2. Choose best real render.
3. Review motor stability.
4. Review identity.
5. Review story state.
6. Confirm prepared Continuation Zone.
7. Select Extend Anchor from stable propulsion.
8. Build next Extend prompt from Continuity State.
9. Generate alternatives.
10. Reject any extension with restart/drift.
11. If accepted, inspect transition.
12. Use Get Whole Song.
13. Re-review the Whole Song, because a clean extension alone does not prove a clean combined result.
14. Update Continuity State and Extend Map.
15. Repeat or finalize.

## Stage prompt rule

An Extend prompt must carry enough context to preserve:
- BPM;
- motor identity;
- track identity;
- current story state;
- already transformed motifs;
- current energy;
- next intended evolution;
- no-restart intent.

It should not restate the entire system.

## Whole Song gate

`EXTENSION_ACCEPTED + TRANSITION_ACCEPTED = WHOLE_SONG_ALLOWED`

If either is false, do not promote.
