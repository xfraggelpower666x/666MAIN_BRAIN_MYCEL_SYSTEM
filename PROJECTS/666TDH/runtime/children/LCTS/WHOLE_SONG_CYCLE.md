# Whole Song Cycle

A Whole Song is a promoted continuity snapshot, not merely a stitched file.

## Required sequence
BASE
→ REVIEW
→ EXTEND
→ REVIEW
→ TRANSITION CHECK
→ GET WHOLE SONG
→ WHOLE SONG REVIEW
→ STATE UPDATE

Repeat until final-stage readiness.

## Why Whole Song needs a second review
Joining can expose:
- subtle timing seams;
- changed bass weight;
- phrase discontinuity;
- loudness reset;
- different stereo identity;
- duplicated semantic events;
- apparent new intro.

Therefore:
`CLEAN EXTENSION != VERIFIED WHOLE SONG`

## Version naming suggestion

`TRACKID_WHOLE_A`
`TRACKID_WHOLE_AB`
`TRACKID_WHOLE_ABC`
`TRACKID_FINAL`

The Continuity State records only accepted versions.
