# Extend Decision Gate

Before Get Whole Song, answer from the actual rendered extension and join:

TEMPO_STABLE?  
GRID_STABLE?  
KICK_IDENTITY_STABLE?  
BASS_IDENTITY_STABLE?  
PHRASE_STABLE?  
TRACK_IDENTITY_PRESERVED?  
NO_FALSE_INTRO?  
NO_FALSE_OUTRO?  
STORY_CONTINUES?  
TRANSITION_CLEAN?  
PERCEIVED_SPEED_STABLE_ENOUGH_FOR_DJ_USE?

If sufficiently confirmed:
`GET_WHOLE_SONG_ALLOWED`

Otherwise:
`REGENERATE_EXTENSION`
or
`ANCHOR_CHANGE_REQUIRED`

The gate is a promotion decision, not a composer. It prevents an attractive extension from becoming authority when continuity is broken.
