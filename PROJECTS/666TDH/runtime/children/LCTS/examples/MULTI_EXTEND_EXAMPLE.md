# Multi-Extend Example

TARGET=20+ minutes  
STAGES=A -> B -> C -> D -> FINAL

## State evolution
A introduces Motor M1, motif X and question Q.  
B preserves M1, transforms X spatially and reveals consequence Q1.  
C preserves M1, removes most upper density, lets X return as a sparse memory, then introduces contradiction Q2.  
D preserves M1, expands the contradiction through severe psychoacoustic motion and transforms X into X4.  
FINAL recalls X4, resolves or suspends Q2 according to the story, then creates the first true outro.

## Why this remains one track
- same temporal motor;
- same underlying sonic ancestry;
- every new event refers to prior history;
- no extension reintroduces the premise;
- no intermediate stage uses a final cadence;
- finalization happens once.
