# 12-Minute Build Example

This is an architectural example, not a timing lock.

## Track
TARGET=~12:00  
BPM=150  
STAGES=A + B + FINAL

### Stage A ~0:00–5:30
- 0:00–1:00 DJ-readable motor establishment
- 1:00–2:30 first spectral field
- 2:30–4:10 first development
- 4:10–5:00 first major event
- ~5:00–5:30 continuation zone

Target anchor: approximately 5:10–5:25, only if actual render has stable full propulsion and no ending gesture.

### Stage B ~5:30–8:40
- no new intro;
- same motor;
- transformed motif;
- deeper story consequence;
- more spatial contradiction;
- second major event delayed until relation is earned;
- continuation zone near stage end.

Get Whole Song and re-review.

### Final ~8:40–12:00+
- continue from accepted anchor;
- recall transformed Stage A motif;
- spend unresolved pressure;
- final convergence;
- DJ-readable release;
- actual end.

Success is not “12 minutes”.
Success is one identity surviving all joins.
