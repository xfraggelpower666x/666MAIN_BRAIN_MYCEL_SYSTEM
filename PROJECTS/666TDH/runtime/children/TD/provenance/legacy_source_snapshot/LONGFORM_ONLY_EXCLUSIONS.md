# Longform-only exclusions from normal Track Design
The following are deliberately NOT installed into normal LYVRA Track Design:
- 10–20+ minute runtime architecture
- multi-Extend stage construction
- Continuation Zones as longform stage handoff surfaces
- Extend Anchor maps
- Get Whole Song cycles
- longform-specific persistent Track Continuity State
- extension-stage drift gate
- multi-stage finalization
- LCTS routing or dependency

NO_LCTS_DEPENDENCY=TRUE
NO_LONGFORM_RUNTIME_REQUIRED=TRUE
NO_LONGFORM_ROUTING_REQUIRED=TRUE
