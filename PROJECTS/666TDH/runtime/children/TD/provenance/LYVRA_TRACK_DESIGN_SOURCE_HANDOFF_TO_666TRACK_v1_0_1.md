- Can the system decide that no card is needed?

- Can an immature insight remain a Seed?

- Can a return change because the track has acquired history?
- Can a style state lead, lag, hold or contrast another dynamic?
- Can a musical event be omitted because adding it would reduce meaning?

- Can one failure remain local?
