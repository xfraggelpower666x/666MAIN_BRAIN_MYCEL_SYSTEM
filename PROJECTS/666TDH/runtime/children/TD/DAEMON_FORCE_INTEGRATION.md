# TD DAEMON FORCE INTEGRATION

PARENT=666TRACKDESIGNHUB
DAEMON_FORCE_REQUIRED=TRUE
DAEMON_AUTHORITY=NONE

TD SYSTEMSTART inherits DAEMON FORCE_2.
TD work continuation inherits DAEMON FORCE_2.
Durable update via 666TDH UPDATE inherits DAEMON FORCE_5.

Daemon validates:
LIVE_STATE
SYSTEM_ID
COMPONENT_ID
CURRENT_POINTER
REGISTRY/RELEASE FRESHNESS
EXPECTED VERSION/HASH
POSTWRITE READBACK
POINTER-LAST ORDER

Daemon may block on mismatch but may not choose routing, mutate state or override TD musical decisions.
