# Real vs perceived time

REAL_TIME_CARRIER=KICK <-> STRAIGHT_16TH_PSYBASS <-> BAR_GRID <-> SHARED_4_4_TIME <-> PRIMARY_MOTOR_CONTINUITY <-> DJ_MIXABILITY.

PERCEIVED_TIME_FIELD=PSYCHOACOUSTICS <-> SPECTRAL_GOA <-> FOREST_CHAOS <-> PHASE <-> SPACE <-> DENSITY <-> PHANTOM_MOTION.

PSYCHOACOUSTIC_TIME_DISTORTION != REAL_TEMPO_DISTORTION.
REAL_TEMPO_WAVE_BEHAVIOR=FORBIDDEN.
PERCEIVED_TIME_MAY_BEND=TRUE.
REAL_TIME_MUST_REMAIN_CONTROLLED_BY_DEFAULT=TRUE.

Validation must distinguish:
BPM_STABILITY
GRID_STABILITY
PRIMARY_MOTOR_CONTINUITY
PROPULSION_IDENTITY_CONTINUITY
SECTION_TO_SECTION_DRIVETRAIN_CONTINUITY

Stable BPM or grid alone does not prove DJ-stable locomotion.
