The Hub companion and child companion cards are different scoped views of
the same native Daemon; neither starts a separate service. Show evidence,
blockers, unknowns, the next safe action and a countercheck for the currently
selected target. FSE and SHACHIVITI source identity holds must remain
visible. In the local HTML menu `hide` is view-only and session-only.

The legacy DAEMON_MENU.md contains historical command examples not currently
registered in runtime/TRIGGERS.json. R2 presents only routed commands as
copy actions. No `666TDH DAEMON ...` runtime trigger is made operational
without a separate tested router change. A daemon recommendation or UI
click never performs SYSTEMSTART, UPDATE, a foreign write or a handoff.
