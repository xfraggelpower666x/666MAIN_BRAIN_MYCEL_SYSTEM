# Daemon Menu

Daemon is autoactive; no START command is required.

Controls:
- `666TDH DAEMON STATUS`
- `666TDH DAEMON NEXT`
- `666TDH DAEMON MENU`
- `666TDH DAEMON CONTINUE`
- `666TDH DAEMON BACK`
- `666TDH DAEMON HELP`
- `666TDH DAEMON STOP`
- `666TDH DAEMON WEITER`
- `666TDH DAEMON NEW CHAT`

STOP disables the companion for the current session only.

## DTSTE Child 3 Adapter
TARGET_SYSTEM_ID=666DTSTE-001
TARGET_BRANCH=DTSTE
DTSTE_SYSTEMSTART_FORCE=2
DTSTE_WEITER_FORCE=2
DTSTE_NEW_CHAT_FORCE=4
DTSTE_AUTOMATIC_HANDOFF_FORCE=4
DTSTE_UPDATE_FORCE=5
DTSTE_HOST_RECOVERY_FORCE=5
DTSTE_DAEMON_AUTHORITY=NONE
DTSTE_NATIVE_IDENTITY_PRESERVED=TRUE
