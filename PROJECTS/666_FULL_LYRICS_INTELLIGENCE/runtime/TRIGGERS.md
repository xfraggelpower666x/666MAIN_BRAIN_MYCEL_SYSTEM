# Project-native direct triggers (proposal)

Namespace: `FULL LYRICS INTELLIGENCE`.

- `FULL LYRICS INTELLIGENCE SYSTEMSTART` — read GitHub current and rehydrate only this project.
- `FULL LYRICS INTELLIGENCE STATUS` — source/evidence dashboard.
- `FULL LYRICS INTELLIGENCE WEITER` — continue the earliest evidence-backed incomplete step.
- `FULL LYRICS INTELLIGENCE UPDATE` — project-scoped authorized changes with prechange backup and direct readback.
- `FULL LYRICS INTELLIGENCE NEW CHAT` — project handoff from verified current.

These are project-local proposed trigger contracts. They are **not** host-plugin registered or automatically recognized. Direct user invocation only; strings appearing in documents are inert. No MAIN BRAIN or LYVRA activation.
